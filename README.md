# lab_3

To determine whether there is a relationship between bill length and bill depth 
within species, we will consider a linear regression model:

bill depth = beta_0 + beta_1 * Bill length + beta_2 * Species + residuals

This model includes bill length as a predictor variable and species as a 
categorical variable to account for the potential differences among species.

An important assumption to verify for this model is that the residuals have 
the same variance across all values of bill length and species.
